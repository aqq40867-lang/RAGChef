# Cumberland Sausage Casserole

## Ingredients
Cumberland sausages, onions, carrots, canned tomatoes, beef stock, herbs.

## Steps
1. Brown the sausages, then set aside.
2. Soften onions and carrots in the same pan.
3. Add tomatoes, stock, and herbs, then return the sausages to the pan.
4. Simmer until the sausages are cooked through and the sauce has thickened.
