# RAGChef

A recipe Q&A tool built on Retrieval-Augmented Generation (RAG): Chrome extension frontend + FastAPI backend. Users ask a question in the extension, the backend retrieves relevant content from a local recipe knowledge base using TF-IDF, then passes it to DeepSeek to generate an answer grounded strictly in the retrieved content.

---

# Features

- Recipe Q&A over a knowledge base of 50 English recipes (20 Chinese home-style dishes + 30 British classics), covering meat/vegetarian/soup/staple/dessert
- TF-IDF retrieval + DeepSeek generation; clearly says so instead of making things up when nothing relevant is found
- Chrome extension frontend for asking questions directly in the browser; FastAPI exposes a `/ask` endpoint
- Fails fast on missing config (API key / empty knowledge base) at startup; returns a friendly message instead of crashing when the LLM call fails
- pytest suite covering retrieval logic and the API (with the LLM mocked), plus an optional real DeepSeek integration test

# Getting Started

1. Set your DeepSeek API key in `server/.env` (see `server/.env.example`; get a key at [platform.deepseek.com](https://platform.deepseek.com)).

2. Start the backend, either way:

```bash
# Run locally
cd server
pip install -r requirements.txt
uvicorn app:app --reload

# Or with Docker
docker compose up --build
```

Runs on `http://127.0.0.1:8000` by default. `GET /` confirms the server is up, `POST /ask` with `{ "question": "..." }` returns an answer.

3. Load the Chrome extension: open `chrome://extensions`, enable "Developer mode" → "Load unpacked" → select the `extension/` directory. If your backend isn't running at the live Render URL, update the request address in `extension/manifest.json` and `popup.js` accordingly.

Run tests: `cd server && pip install -r requirements-dev.txt && pytest`

# Example

```bash
curl -X POST http://127.0.0.1:8000/ask \
  -H "Content-Type: application/json" \
  -d '{ "question": "How do I make Kung Pao Chicken?" }'
```

Response (illustrative — the actual wording is generated by DeepSeek and varies, though it stays grounded in the retrieved recipe content):

```json
{
  "answer": "To make Kung Pao Chicken: dice and marinate chicken breast, stir-fry dried chilies until fragrant, add the chicken and stir-fry until it changes color, then add the sauce mixture (soy sauce, vinegar, sugar) and peanuts, tossing until glazed."
}
```

Asking something outside the knowledge base (e.g. a French dessert) returns: "No relevant information was found in the current recipe library."
